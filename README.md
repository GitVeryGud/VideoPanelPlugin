# Video Panel Plugin
 
A [MusicBee](https://www.getmusicbee.com/) plugin that embeds a [VLC](https://www.videolan.org/vlc/) video player directly into the MusicBee interface, letting you play music videos alongside your library.
 
## Installation
 
1. Download the latest release from the [Releases](../../releases) page.
2. Add the plugin at **Edit Preferences (CTRL + O) > Plugins > Add Plugin...**.
3. Choose the VideoPanelPlugin zip.
3. Restart MusicBee.
4. Enable the plugin at **Edit Preferences (CTRL + O) > Plugins**.

OR  

1. Download the latest release from the [Releases](../../releases) page.
2. Move the unzipped contents of VideoPanelPlugin.zip into your MusicBee `Plugins` folder, typically:
```
   C:\Program Files (x86)\MusicBee\Plugins\
```
3. Restart MusicBee.
4. Enable the plugin under **Edit > Preferences > Plugins**.

## Usage
 
1. Go to **View > Arrange Panels... > available elements**.
2. Choose the newly added "video panel" and put it wherever you prefer.
3. Now you can watch videos on MusicBee.
